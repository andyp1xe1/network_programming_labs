# Networks Programming Labs

## [Lab 1: HTTP File Server](./packages/lab1/)
Single-threaded HTTP server implementation with file serving, directory listings, and MIME type support. Built with Python and Docker.

## [Lab 2: Concurrent HTTP Server](./packages/lab2/)  
Multi-threaded server demonstrating concurrency concepts, race conditions, and thread synchronization. Includes rate limiting and performance analysis.

## [Lab 3: Memory Scramble Game Server](./packages/lab3/)
Advanced concurrent game server implementing MIT 6.102 PS4 specification. Features real-time multi-player support, comprehensive ADT design, and web interface. Built with Go.
